# BrincaMundo ✨

BrincaMundo é uma loja virtual fictícia de brinquedos, criada como projeto básico de desenvolvimento web.

## Recursos

- Design responsivo e moderno.
- Barra de navegação com seções.
- Banner principal com chamada para ação.
- Filtros por categoria.
- Campo de pesquisa de produtos.
- Cards de produtos com preço e avaliação.
- Carrinho lateral com atualização de quantidade e total.
- Botão para remover produtos do carrinho.
- Mensagens de feedback para o usuário.
- Seção de benefícios e newsletter demonstrativa.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro (sem bibliotecas externas)

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno.

## Arquivos

- `README.md`: documentação do projeto.
- `index.html`: estrutura da página.
- `style.css`: identidade visual e responsividade.
- `script.js`: pesquisa, filtros e carrinho interativo.

> Projeto fictício para fins educacionais. Não realiza pagamentos reais.
